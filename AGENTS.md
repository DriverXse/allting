# AllTing assistant entry point

Read [AI-AGENT.md](AI-AGENT.md), [PRODUCT-SPEC.md](PRODUCT-SPEC.md) and
[README.md](README.md) before working on this project. They define the actual
architecture, version 1 product rules, authorization boundaries, setup steps and

Keep the interface in natural Swedish and documentation in English. Never add
monetary functionality, include private runtime data, reuse another operator's
hosting identity, or replace server authorization with UI-only checks.
